# GDXR
V2 of me trying to make extension that adds VR support for gdevelop using the webXR api

# How to play/start
1. To make this work, start the preview over WiFi/LAN
2. go to `chrome://flags/`
3. Search `Insecure origins treated as secure` -> Enter the url of the preview
4. Refresh browser
